# Gari Yangu – frontend

React + Vite. Talks to the Flask backend in `../backend` through `src/api.js`.

    npm install
    npm run dev      # http://localhost:5173  (proxies /api to http://localhost:8000)
    npm run build

Start the backend first – see the root README. Demo accounts (password `demo1234`): buyer@demo.com, dealer@demo.com, admin@demo.com
