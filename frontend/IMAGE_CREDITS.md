# Demo vehicle image credits

The frontend uses representative photographs only when a dealer has not uploaded images for a specific listing. Dealer-uploaded images always take precedence. These stock/demo photos must not be represented as photographs of the exact vehicle being sold.

- Toyota Land Cruiser Prado representative photo: Ominae, Wikimedia Commons, [Toyota Land Cruiser Prado Front.JPG](https://commons.wikimedia.org/wiki/File:Toyota_Land_Cruiser_Prado_Front.JPG), licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- SUV, sedan, pickup and Mazda CX-5 example photos: Unsplash image CDN URLs in `src/vehiclePhotos.js`, used under the [Unsplash License](https://unsplash.com/license).
- The hero photograph is a representative automotive image from Unsplash.

If you deploy the site commercially, retain this credit file and re-check the license terms for each image source. For production vehicle listings, use photos supplied by the actual seller.
